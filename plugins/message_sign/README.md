# 群签到与今日运势

在已有群签到中融合今日运势、每日宜忌、经验等级和图片卡片。插件代码仍为 message_sign，入口仍为“签到”，也支持平台已有的 /签到、#签到 前缀。没有额外的 jrys 或今日运势命令。

## 使用

- **签到**：领取原有积分奖励和新增经验，查看运势卡片；展示当前积分、连签、累计签到和今日签到顺序。
- **重复签到**：查看相同的当天运势，不重复领取积分、经验或增加签到次数。
- **补签**：保留原有昨天补签、扣积分和恢复连签规则，不补发经验或刷新今日运势。

日期统一采用项目的北京时间。运势使用租户、群、用户和日期生成稳定随机结果，重复发送、服务重启或切换文字模式不会重抽；只用于娱乐。

## 与现有数据兼容

现有 SignInRecord、SignInHistory 和 PointsService 积分账本继续使用，旧积分、签到次数和连签记录不改写。上游插件的 coin 在这里直接使用现有积分余额，不建立第二套货币。积分奖励仍使用原有基础积分、连签周期和上限规则，不由运势改变。

新增经验及当天运势使用租户和插件绑定隔离的 PluginStateStore；每个用户/群只保留一份经验档案和当天运势，不累计历史图片或每日快照，不需要数据库迁移。经验与本次签到、积分在同一事务内保存。升级前的签到不追溯发放经验；当天已经签到的老用户再次查询仅展示运势，次日真实签到开始获得经验。

等级沿用上游的 21 档（Lv.0 至 Lv.20）。默认经验范围为 1–100，当天运势越高越容易获得较多经验。补签、重复签到不发经验。

## 配置

管理页“群签到”提供原有五项积分配置和以下新增配置：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| fortune_enabled | true | 启用今日运势、宜忌和经验等级；关闭则沿用文字签到 |
| fortune_image_enabled | true | 发送卡片图片；关闭则发送完整文字运势 |
| background_url | 原插件默认插画的固定版本 CDN 地址 | 公网 HTTP/HTTPS 背景图片直链；留空或加载失败使用内置背景 |
| sign_exp_min | 1 | 每次真实签到经验下限 |
| sign_exp_max | 100 | 每次真实签到经验上限 |

未新增公开命令，不需要重新绑定插件。现有群启用范围和原有配置保持生效。

## 图片生成

使用项目已有的 Playwright，背景、默认头像和中文字体随插件提供。昵称和头像通过平台 IdentityDirectory 读取当前渠道、当前群的已同步成员资料：本群群昵称/昵称优先，头像取成员资料；资料不完整时按平台统一规则从好友资料补齐，再回退消息昵称和默认头像。每次签到重新解析资料，重复签到也会显示更新后的群昵称和头像，不改写原始消息。

成员头像在签到事务提交后下载，通过平台公网地址校验（包括重定向）、2 秒请求时限、2 MiB 和 400 万像素限制，转换成小尺寸 PNG 后内嵌到卡片。地址缺失、失效或图片损坏时只回退默认头像，昵称和签到卡片仍正常显示。浏览器本身不请求外网，也不依赖 QQ 头像。每日一言从本地文案中稳定抽取，避免第三方接口故障影响签到。

Windows 自动查找本机 Chrome/Edge；Linux 自动查找系统 Chromium/Chrome，找不到则使用 Playwright 安装的 Chromium。浏览器缺失或渲染失败会返回完整文字结果，已成功发放的积分和经验不会回滚。只有需要图片渲染的环境才需准备浏览器，例如在对应 Python 环境执行：

    python -m playwright install --with-deps chromium

背景直链与头像并行下载，背景有 3 秒、5 MiB 和 1200 万像素上限，统一缩小并转换成 JPEG 内嵌，浏览器不会直接访问配置地址。卡片生成在签到事务提交后执行，浏览器渲染设有 7 秒限时；图片直接以平台标准 base64 回复返回，不写共享临时文件。Docker 镜像内安装系统 Chromium，无需运行时下载浏览器。
