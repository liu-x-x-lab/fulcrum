# 音乐点播

本插件 3.0.0 直接对接 **L-1124/QQMusicApi v0.9.0 Web 服务**，按该版本的路由和标准化响应实现，不依赖 Koishi。Fulcrum 中的 `guess_song`（猜歌）是独立插件，此次不改动它的旧服务接口。

## 接入与升级

1. 单独运行 QQMusicApi v0.9.0 Web 服务，将其根地址填入插件的“QQMusicApi 服务地址”。支持反向代理的路径前缀；不要填写具体接口路径。
2. QQ 账号登录、Cookie、会员权限和账号池由 QQMusicApi 服务管理。不要把 QQ 登录凭证填进 Fulcrum 插件配置。
3. 如果反向代理要求 `Authorization: Bearer ...`，填写可选的“反向代理密钥”。QQMusicApi 的登录凭证不是此密钥。
4. 选择音质、回复方式和候选数量，保存并启用机器人绑定及所需的群作用域。

这是服务协议升级：旧版 `/Search`、`/Song_V1` 接口及 `quality` 配置不再使用。升级时必须把 `api_base` 改为 QQMusicApi 0.9.0 服务；旧的 `quality` 不会自动映射，未设置新 `file_type` 时使用 MP3 128k。已有自定义触发命令会保留，要使用新功能请在后台触发命令中加入“搜歌、选歌、歌词”。插件不会探测或回退到旧服务，也不会自动部署上游。

需要上游的全局账号池时，参考该版本 `web/config.example.toml` 的配置：

```toml
[credential]
enabled = true
api = { song = ["get_song_urls", "get_song_url"] }
```

实际账号通过上游的登录和凭证管理功能配置。歌曲能否播放仍取决于账号权限、单曲购买和设备限制。

## 命令

| 命令 | 行为 |
| --- | --- |
| `点歌 晴天` | 播放搜索到的第一首 |
| `点歌 晴天 -n 2` | 播放本次搜索结果第 2 首，也支持 `点歌 -n 2 晴天` |
| `搜歌 晴天` | 展示候选列表，默认 5 首，最多 10 首 |
| `选歌 2` | 播放当前发送者最近列表的第 2 首，默认 180 秒有效 |
| `歌词 晴天` | 查询第一首的歌词，去掉逐行时间标签 |

兼容点歌别名：`音乐`、`音乐点播`、`点播音乐`、`音乐点歌`，并支持平台命令前缀。

选歌需要真实聊天上下文。列表通过平台状态库按租户、机器人绑定、渠道、会话、发送者和微桥设备/账号/登录会话隔离。更换服务地址、代理密钥或音质后原列表失效；新点歌或搜歌开始前清除旧列表，失败后不会误选上一次的歌。每个绑定最多保留 256 份列表，过期清理与容量淘汰均受绑定范围约束。状态只存歌曲 MID、歌名、歌手、封面标识、媒体 MID 和歌曲类型，不保存原始响应、播放地址或 VKey。

## 回复与故障处理

- 自动：微桥使用标准 `music` 回复，由已有渠道层生成 `send_music_card` 手机命令；其他渠道返回歌名、歌手、歌曲页面和播放链接。
- 文件：返回文件和链接，扩展名按上游实际文件格式生成；Telegram 当前使用文本链接。
- 文本：返回歌曲页面及播放链接。签名播放地址可能过期，过期后重新点歌。
- 音乐卡片可附带最多 5000 字符的歌词。歌词属于可选信息，获取失败仍发送已授权歌曲。文件、文本模式不额外获取歌词；独立歌词命令始终可用。
- 登录失效、访问策略拒绝、共享额度耗尽、上游限流、歌曲无权限、VKey 失败、设备限制、超时和协议不兼容分别提示。可配置接口失败时静默。
- 单次流程默认总时限 25 秒，单个请求默认 8 秒，多个接口共用剩余预算；不自动重试，不自动换歌或降音质。并发保护在单个 Fulcrum 工作进程内生效：同一会话发送者同时最多一条请求、每绑定最多 16 条、全进程最多 64 条。跨进程保护依靠上游 Web 服务的缓存、请求合并与并发控制。

发送中如果微桥登录身份变化、渠道停用/删除或插件绑定停用，丢弃结果。手机是否实际发送成功沿用现有命令回报机制；入队不等于送达，失败不自动重复发送。

## v0.9.0 接口约定

响应封装为 `{"code":0,"msg":"ok","data":{...}}`，使用 Web 标准化字段，不解析旧服务格式或 SDK 别名。

| 用途 | GET 路径 | 关键参数与字段 |
| --- | --- | --- |
| 搜索 | `/search/search_by_type` | `keyword`、`search_type=0`、`num`、`page=1`、`highlight=false`；读取 `data.song` |
| 补充详情 | `/song/query_song` | `value=MID`、可选 `song_type`；读取 `data.tracks`，严格匹配 MID |
| 获取播放地址 | `/song/{mid}/url` | `file_type` 整数、可选 `media_mid` / `song_type`；读取 `data.data`，严格匹配 MID 和 `result=0` |
| CDN | `/song/get_cdn_dispatch` | 当 `purl` 为相对路径时读取 `data.sip` 并安全拼接 |
| 歌词 | `/song/{mid}/lyric` | 传递实际 `song_type`（包括 0）；读取已解密的 `data.lyric` |

Web 的 `file_type` 使用整数映射，不能直接传 SDK 枚举名。该版本选用的映射如下：

| 插件配置 | Web 整数 | 扩展名 |
| --- | ---: | --- |
| `mp3_128` | 13 | `.mp3` |
| `mp3_320` | 12 | `.mp3` |
| `flac` | 7 | `.flac` |
| `ogg_192` | 10 | `.ogg` |
| `ogg_320` | 9 | `.ogg` |
| `aac_96` | 15 | `.m4a` |
| `aac_192` | 14 | `.m4a` |

仅开放可直接播放的常见格式，不将加密或试听文件冒充普通音频。
